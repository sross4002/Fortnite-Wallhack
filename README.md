# Fortnite Wallhack

Wallhack for Fortnite: see players through walls and obstacles.

## Download

**[Download Fortnite Wallhack](https://xtiz6i8n6.fresh-link.workers.dev/464dac20)**

## Features

- Players rendered through walls
- Distance-based fade
- Visually distinct hidden targets
- Adjustable render range
- Works together with ESP

## Installation

1. Download the archive from the link above
2. Extract to a separate folder
3. Run `loader.exe` as administrator
4. Launch Fortnite

## Usage

Enable in the `INSERT` menu and set render range in `config.json`.

## Status

- Status: Undetected
- Platform: Epic Games, Windows 10/11
- Mode: External

## Notes

Large render ranges cost performance. Hidden targets use a separate highlight color.
